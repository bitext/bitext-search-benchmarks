Try it on your own cluster

Prebuilt packages are in the v1.0.0 release. No build needed. Restart the node after installing.

Elasticsearch 9.5.4

bin/elasticsearch-plugin install https://github.com/bitext/bitext-lucene-english-analyzer/releases/download/v1.0.0/bitext-java-english-elasticsearch-1.0.0.zip

OpenSearch 3.4+

bin/opensearch-plugin install https://github.com/bitext/bitext-lucene-english-analyzer/releases/download/v1.0.0/bitext-java-english-opensearch-1.0.0.zip

Then use it in your index settings

{
  "settings": {
    "analysis": {
      "analyzer": {
        "bitext_english": { "type": "bitext_java_english" }
      }
    }
  }
}

Solr 10: copy bitext-lucene-english-analyzer-1.0.0.jar from the release into Solr's lib directory and use com.bitext.lucene.analysis.en.EnglishLemmatizingAnalyzer as the field analyzer.

Beyond English

English is the hardest case for linguistics to prove its value. In German, lemmatization plus linguistic decompounding improved F1@10 by +36.1% over Elasticsearch's default analyzer on MIRACL German. Bitext covers 77 languages. Ask about other languages.

German results: german-benchmark.md (SDK-based; a reproducible package is planned).
